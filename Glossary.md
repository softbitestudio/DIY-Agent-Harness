__LangGraph Checkpointer:__
 Like save points in a video game—remembers where the agent left off so it never forgets context if the program restarts.

__gVisor (runsc):__ 
A bulletproof glass box placed inside Docker so untrusted AI-generated code can't break out and touch your actual machine.

__LiteLLM Proxy:__
 A traffic controller and universal translator between model providers that caches repeated prompts to save money.

__Server-Sent Events (SSE):__
 A live radio feed emitting real-time updates straight from your Python server to the web browser without forcing full page reloads.

__Vector RAG (sqlite-vec):__ 
A smart search index allowing agents to query huge libraries of skills only when specifically needed, keeping prompt context lightweight.
